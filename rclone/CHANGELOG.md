# 更新记录

## 1.0.0 — 2026-10-05

- 首次正式发布 Windows 交互式 rclone 磁盘管理器。
- 通过 winget 安装、查询和卸载 rclone 与 WinFsp；固定精确包 ID，报告退出码及部分完成状态。
- 卸载组件前拒绝运行中的 rclone 和启用的管理器自启任务。
- 保存多盘符、远端子目录、网络/固定磁盘、缓存、容量显示和只读设置。
- 安全卸载检查文件活动及未完成上传，保留远端配置、缓存和日志。
- 支持当前用户无窗口登录自启、延迟启动、失败重试和日志诊断。
- 提供 Windows PowerShell 5.1 / PowerShell 7 隔离测试与可选本机 RC 集成测试。

限制：Linux 尚未实现；真实 WinFsp 挂载、重启恢复和 winget 安装/卸载仍需在测试机上手动验收。GUI 的挂载列表仅显示其连接的 rclone 实例，本脚本的挂载请通过菜单管理。
