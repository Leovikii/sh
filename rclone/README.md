# rclone 磁盘管理 v1.0.0

适用于支持 winget 的 Windows 10/11、Windows PowerShell 5.1 或 PowerShell 7。通过菜单 **9 组件安装管理** 安装 rclone 和 WinFsp。Linux 尚未实现。

源码及测试沿用仓库根目录的 GPL-3.0 许可证。rclone 和 WinFsp 由 winget 下载，使用各自许可证，不包含在脚本发布包中。

## 启动

在普通权限 PowerShell 中执行（将路径改为脚本实际位置）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\路径\RcloneDriveManager.ps1"
```

此处 ExecutionPolicy Bypass 仅影响本次进程，不修改系统执行策略。不需要管理员权限。若计划任务操作被组织策略禁止，脚本会报告错误，不会自动提权。

从 GitHub Release 下载并解压发布包，进入脚本所在目录执行：

```powershell
Unblock-File .\RcloneDriveManager.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\RcloneDriveManager.ps1
```

从旧脚本升级时继续使用相同 Windows 用户和 StoreRoot（默认路径不变）。下载新版后，对已有盘符重新选择菜单 **6 开启自启**，更新自启使用的脚本副本。无需重建配置或删除缓存。

首次使用按以下顺序操作：

0. **组件安装管理**：选择菜单 9，再选择 1 安装两个组件。安装完成后如有重启提示，请重启 Windows。

1. **配置远端**：调用原生 `rclone config` 向导，设置 WebDAV 地址、用户名和密码。已有 `omv` 等远端可跳过。
2. **挂载设置**：选择已有远端，保存盘符、显示模式、缓存等选项。仅保存，不立即挂载，也不开启自启。
3. **挂载**：按已保存的设置运行 `rclone mount`，盘符出现在资源管理器中。

远端配置负责“访问哪里”；挂载设置负责“使用哪些参数”；挂载负责“立即运行”。挂载设置和自启管理由本脚本提供。创建挂载设置不会修改原有远端 URL、用户名、密码。

## 组件安装管理

主菜单 **9** 提供安装两个组件、分别安装、查看状态、分别卸载和卸载两个组件。包 ID 固定为 `Rclone.Rclone`、`WinFsp.WinFsp`，安装和卸载指定 `--exact --source winget`；状态查询同时显示实际 rclone 路径和 WinFsp 服务状态。

需要 `winget.exe` 可用。缺失时从 Microsoft Store 安装或更新“应用安装程序”，重新打开终端。网络或源失败会保留 winget 输出及退出码；已安装且无更新、未找到待卸载组件会单独提示。两个组件顺序处理，一项失败立即停止，已完成的步骤不自动回滚，修复问题后可分别重试。

管理器始终以普通用户运行，安装程序需要权限时由 winget/安装程序显示 UAC；不要以管理员身份启动整个管理器。脚本接受 winget 源协议和所选安装包协议，不自动修改执行策略、系统安全策略或执行重启。

卸载前会拒绝存在任何运行中的 `rclone.exe` 或仍启用的本管理器自启任务的情况；先通过菜单 7 关闭自启、菜单 4 安全卸载磁盘，并退出其他 rclone 实例。WinFsp 是共享组件，卸载前还需手动退出其他依赖 WinFsp 的应用。检查不能消除其他程序随后启动的竞争，因此卸载期间不要开启挂载。

卸载不会清理本管理器的 JSON、缓存、日志或远端配置。便携版或 winget 无法识别的安装不会被脚本删除；由其原安装方式管理。若更换了 rclone 安装路径，旧配置中的路径不存在时会自动重新查找；仍存在的自定义路径优先使用。

## 可配置项目

| 项目 | 默认值和含义 |
|---|---|
| 远端 | 从已有远端中选择，支持指定子目录 |
| 盘符 | X，可自定义 D 到 Z；已占用盘符会拒绝 |
| 挂载模式 | network：显示在网络位置，推荐；fixed：显示为固定磁盘 |
| 缓存 | full：读写缓存，推荐；writes：写缓存；off：无磁盘缓存 |
| 缓存上限 | 20G，清理目标，不是硬限制；打开或未上传文件可能超过 |
| 总容量显示 | auto，使用服务端信息；缺失时可能显示约 1 PiB |
| 自定义显示容量 | 例如 500G、2T，仅覆盖总容量，不改变服务端配额 |
| 只读 | 默认关闭，可开启 |
| 登录自启 | 默认关闭；菜单 6 开启，菜单 7 关闭 |

两种显示模式均通过 WinFsp 连接 rclone，不会改变 WebDAV 协议。脚本不修改 HTTP/HTTPS。

WebDAV 服务端经常没有 rclone 可读取的容量信息。自定义总容量可以消除总量的 1 PiB 占位值，但已用和剩余容量仍可能不准确。脚本不默认启用递归扫描远端的 `--vfs-used-is-size`；大型目录扫描可能很慢，统计也未必代表整个存储池的配额。

## 自启与卸载

- 开启自启创建 `RcloneDriveManager-X` 等任务：当前用户登录后约 20 秒启动，普通权限运行，没有任务运行时限；失败每分钟重试，最多 10 次。
- 自启使用 `wscript.exe` 无窗口启动器，从创建 PowerShell 进程时即隐藏控制台；启动器等待子进程结束并传递返回码，保留计划任务失败重试。若 Windows Script Host 缺失或被禁用，脚本会报错，不修改该系统策略。
- 更新已有任务：运行新版脚本，选择菜单 **6 开启自启**，再选择原有盘符，即可刷新任务和启动文件；不会立即重新挂载，也不会停止当前磁盘。
- 关闭自启只关闭未来的登录启动，不立即中断当前挂载。
- 菜单 0 退出管理界面后，挂载保持运行。
- 菜单 4 卸载：检查打开文件、排队上传、正在上传及上传失败的文件；有未完成工作或状态不明时拒绝卸载。请先关闭使用该盘的应用，卸载期间不要继续写入。
- 正常卸载使用本机认证控制接口退出 rclone，不执行强制结束进程；尝试清理本脚本独有的网络盘残留记录并刷新资源管理器，不接管其他挂载。
- 菜单 8 删除挂载设置：卸载磁盘，移除本脚本创建的任务及管理配置，保留 rclone 远端、缓存和日志。
- 掉电或关机后，未上传数据保留在缓存中；保留同一配置和缓存再次挂载可尝试继续上传。缓存不是可靠备份，不要在有待上传数据时删除缓存或重新创建配置。

运行文件位于 `%LOCALAPPDATA%\RcloneDriveManager`。每个盘符有独立配置、缓存、日志和运行状态。控制接口仅绑定 `127.0.0.1`，使用随机密码；保存到运行状态中的控制密码使用当前 Windows 用户 DPAPI 保护。WebDAV 凭据仍由原有 rclone 配置管理。

无窗口启动器自身失败记录到对应盘符目录的 `launcher-error.log`；挂载脚本失败记录到根目录 `startup-error.log`；rclone 错误记录到对应盘符目录的 `mount.log`。后台运行不弹出错误窗口，可从菜单 **5 状态** 查看任务返回码和日志位置。

## 测试及手动验收

自动测试脚本模拟计划任务、挂载、卸载和注册表操作，测试文件仅写入 `work\tests`。`-Integration` 额外启动一个仅监听本机的临时 rclone 控制服务，使用测试配置验证认证和退出；不挂载磁盘，不访问远端，不创建真实任务。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Test-RcloneDriveManager.ps1" -Integration
```

真实 WinFsp 挂载、文件读写、资源管理器显示、自启权限和重启恢复尚需手动验收：

1. 新建配置，确认 URL 和原有远端配置未被改动。
2. 挂载并确认选择的盘符及网络/固定磁盘模式。
3. 用可删除的测试文件验证读写，等待上传完成；查询状态后安全卸载。
4. 测试 auto 与自定义总容量，核对其显示限制。
5. 开启自启，登录后检查盘符和任务状态；关闭自启后确认下一次登录不会恢复。
6. 测试占用盘符、断网和打开文件时的错误提示，确认不会强制终止其他挂载。
7. 在可恢复的测试机上验证菜单 9 的首次安装、重复安装、拒绝卸载运行中的 rclone、关闭自启后的卸载、取消 UAC 和需要重启的提示。

Linux 尚未实现。远端、子目录、缓存和容量设置独立保存为 JSON，后续可沿用；盘符、WinFsp、计划任务和资源管理器操作需替换为 Linux 挂载点、FUSE 和 systemd。
